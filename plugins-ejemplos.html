PSMenu - Gestión completa de protecciones

GriefPrevention WorldGuard MySQL Support GUI Interactiva Multi-mundo

Gestiona todas tus protecciones fácilmente con comandos intuitivos: /psmenu, /ps home y /ps flag. Interfaz visual moderna con soporte para múltiples sistemas de protección.

🎯 ¡Plugin Disponible Gratis!

PSMenu está disponible completamente gratis para todos los servidores. Si quieres adquirir el plugin o necesitas una versión personalizada, contáctame para más información.

✨ Características Destacadas

• Interfaz intuitiva - Menús interactivos fáciles de usar
• Soporte múltiple - Compatible con GriefPrevention y WorldGuard
• Base de datos - Almacenamiento en MySQL/SQLite
• Personalización - Mensajes y configuraciones editables
• Multi-mundo - Gestión de claims en diferentes mundos
• Permisos avanzados - Sistema de permisos granular
